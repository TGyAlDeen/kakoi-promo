# Kakoi — Promotional Materials

Static site hosting the Kakoi pitch deck, landing page, and user guide.
Built for GitHub Pages.

## What's here

| File | Purpose |
|---|---|
| `index.html` | Hub page linking to all three documents and downloads |
| `KAKOI_LANDING.html` | Single-page promotional site (overview) |
| `KAKOI_GUIDE.html` | Step-by-step user manual |
| `KAKOI_PITCH.html` | Marp-rendered slide deck (open in browser, press `F` for fullscreen) |
| `KAKOI_LANDING.pdf` / `KAKOI_GUIDE.pdf` / `KAKOI_PITCH.pdf` | PDF versions for sharing offline |
| `KAKOI_PITCH.pptx` | Editable PowerPoint version of the deck |
| `slides/slide.001.png` … `slide.037.png` | Individual slide images at 2560×1440 for SNS carousels |

## Source

The sources (Marp markdown, build scripts, screenshot Playwright spec) live in the main
[content-creator](https://github.com/TGyAlDeen/content-creator) repository. The artifacts
here are regenerated locally from those sources and published.
